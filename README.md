# Píldora Bootcamp: Memento y agentes

## Estructura

```
pildora-bootcamp-memento-agentes/
├── notebooks/        # docente, TODO y solución
├── docs/             # teoría en PDF/DOCX
├── web/              # presentación React/Vite
├── .env.example      # plantilla vacía: GROQ_API_KEY=
├── requirements.txt
└── README.md
```

## Puesta en marcha

1. Copia `.env.example` a `.env` y añade tu `GROQ_API_KEY`.
2. Instala dependencias: `pip install -r requirements.txt`
